# RedLab — Fundamentos de Redes

Aplicación web de estudio basada en el documento **“Introducción — Fundamentos de Redes de Comunicaciones”**. Incluye un resumen estructurado, diagramas interactivos y un test dinámico con corrección y calificación.

## Uso local

No requiere instalación ni proceso de compilación.

```bash
python3 -m http.server 8080
```

Abre `http://localhost:8080`.

## Publicación en GitHub Pages

El workflow incluido publica la rama principal automáticamente. En GitHub, ve a **Settings → Pages → Source** y selecciona **GitHub Actions** si no queda seleccionado al crear el repositorio.

## Contenido

- Modelos OSI y TCP/IP.
- Protocolos TCP, UDP, IP y HTTP.
- Estándares IEEE 802.3, 802.11 y 802.16; X.25, Frame Relay, ATM y otras tecnologías del documento.
- Encapsulamiento: segmentos, paquetes/datagramas, tramas y bits.
- Hardware: hubs, switches, puentes, routers y gateways.
- LAN, MAN, WAN, topologías y unicast/multicast/broadcast/anycast.
- Preguntas de opción múltiple, verdadero/falso, completar y respuesta abierta.
